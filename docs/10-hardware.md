# Hardware: физический доступ к авто

## Контекст и ограничения

CarPal — гибридный формат. Владелец использует авто как личное, иногда выставляет в аренду. Машина не должна выглядеть как каршеринг-флот. Оборудование должно быть съёмным со стороны хоста и незаметным снаружи.

---

## Развилка: ключ-бокс vs keyless через приложение

**Keyless (CAN-bus):** как у Яндекс.Драйв, BelkaCar — приложение через Bluetooth/4G отпирает авто, иммобилайзер обходится через CAN-шину. Физического ключа нет вообще.

Плюсы: лучше UX, нет уязвимой коробки, невозможен сценарий "потерял ключ".

Минусы для P2P:
- CAN-адаптер под каждую модель авто — $200–400/авто + установка
- На авто до ~2010 может не работать технически
- Сел телефон / нет связи → арендатор не может открыть машину, нужна резервная процедура

**Вывод: ключ-бокс правильный выбор для MVP.** Низкий CAPEX, работает на любой машине, понятен хостам ("повесил коробку — снял коробку"). Keyless — история для 500+ машин со стандартизированным модельным рядом.

## Ключ-бокс: какой именно

Механические (ручной код, ~$20–40) — **не брать**. Экономия $60 не стоит риска "хост забыл сменить код". Это человеческий фактор который будет стрелять регулярно.

**Bluetooth/OTP (~$80–120) — единственный правильный выбор:**
- Платформа генерирует time-limited PIN через API
- Код работает только в окно бронирования (10:00–18:00)
- Истёк срок — код не работает автоматически
- Следующий арендатор получает другой код

Конкретные модели с API:
- **Igloohome KeySafe Mini** — есть developer API, time-limited PIN
- **Master Lock 4401DLH** (Bluetooth) — enterprise API у Master Lock

## Монтаж

**Приоритет 1 — фаркоп:** утоплен в бампере, почти не видно снаружи. Лучший вариант если есть.

**Приоритет 2 — под бампером на металлическую раму:** требует кастомного кронштейна, но скрытно и не мешает. Работает на авто без фаркопа.

**Не использовать — колёсный диск:** арендатор может повредить при движении, зимой с реагентами замок коррозирует.

## GPS-трекер + реле

**FMB009 — не подходит:** один DOUT, управляет одним реле. Либо замок, либо иммобилайзер — не оба.

**FMB125 — правильный выбор для MVP:**
- 2 DOUT → реле на центральный замок + реле на иммобилайзер
- GPS + GSM + Bluetooth
- ~$80–100/устройство
- Управление: GPRS-команда с бэкенда (Teltonika Codec 12 protocol)

**StarLine E96 BT — альтернатива при масштабировании:**
- CAN + GSM + GPS, официальный fleet API (telematics.starline.ru)
- $150–250/авто, дороже установка
- Оправдано от 50+ авто когда важна надёжность интеграции и меньше кастомного кода

## Модель безопасности: 6 слоёв

Ключ-бокс — один компонент из шести, не центральный:

```
1. KYC арендатора        — верификация до получения кода
2. Депозит в холде       — финансовый залог
3. OTP-код на боксе      — доступ только в окно бронирования
4. Ключ-дубликат         — без оригинала, только открыть/завести
5. FMB125 + реле         — remote cut engine + GPS трекинг
6. Страховка хоста       — покрытие сверх депозита
```

Сценарии:
```
Просроченный возврат:
  → бэкенд → команда на FMB125 → иммобилайзер → авто глохнет

Угон:
  → GPS-координаты в реальном времени → remote cut engine → данные для полиции

Попытка использовать вне бронирования:
  → OTP не работает → авто недоступно
```

Против профессионального угона система не защищает и не должна — это не её задача. Задача: сделать несанкционированное использование достаточно сложным и трекируемым.

## Кто платит за установку

**A. Хост платит сам** — минимальный CAPEX для CarPal, но барьер входа для хостов. Работает если поток аренд очевиден с первого месяца.

**B. CarPal субсидирует первые 20 авто** — $4,500–6,500 total. Возврат через удержание из выплат (~$15–20/мес). Снижает барьер, ускоряет cold start.

**C. Рассрочка** — CarPal закупает оборудование, удерживает ~10% из каждой выплаты хосту до погашения.

## Backend-интеграция

- Igloohome API / Master Lock API: генерация time-limited PIN при создании бронирования
- Teltonika Codec 12: GPRS-команда lock/unlock/cut engine
- Логика: бронирование создано → OTP с окном = время аренды → возврат подтверждён или срок истёк → команда на иммобилайзер если авто не вернулось
