# Hardware: физический доступ к авто

## Контекст и ограничения

CarPal — гибридный формат. Владелец использует авто как личное, иногда выставляет в аренду. Машина не должна выглядеть как каршеринг-флот. Оборудование должно быть съёмным со стороны хоста и незаметным снаружи.

---

## Решение: ключ-бокс + GPS-трекер + реле

Три компонента, каждый закрывает свою задачу:

| Компонент | Задача |
|---|---|
| Ключ-бокс | Физический доступ к ключу |
| Teltonika FMB125 | GPS-трекинг + управление реле |
| Реле × 2 | Центральный замок + иммобилайзер |

---

## Ключ-бокс

**Внешний вид:** металлическая коробка ~12×8×4 см, кодовый замок (4-цифровой или Bluetooth). Крепится шаклом за фаркоп (утоплен в бампере, почти не видно) или за спицу колеса.

**Логика для хоста:**
- Едет сам → снял коробку, убрал в бардачок
- Выставил в аренду → повесил на фаркоп, код передаётся через приложение
- Машина снаружи не отличается от обычного авто

**Два типа:**

*Механическая с ручным кодом* (~$20–40, например Master Lock 5401 аналоги из CIS):
- Хост меняет код вручную перед каждой арендой
- Платформа генерирует код, хост вводит физически
- Риск: хост забыл поменять код после прошлой аренды

*Bluetooth/OTP* (~$80–120, Igloohome KeySafe или аналог):
- Платформа генерирует time-limited код через API
- Код работает только в окно бронирования (например, 10:00–18:00)
- Истёк срок — код не работает, следующий арендатор получает другой
- Рекомендуется: устраняет человеческий фактор хоста

**Проблема с фаркопом:** есть не на всех авто (хэтчбеки, часть седанов). Альтернатива — крепление на колесо, но видно. *[CTO: требование фаркопа как фильтр для хостов?]*

## Teltonika: какой модуль

**FMB009 — не подходит** для полного решения: один DOUT, можно управлять только одним реле (либо замок, либо иммобилайзер).

**FMB125 — правильный выбор:**
- 2 DOUT → реле на центральный замок + реле на иммобилайзер
- GPS + GSM + Bluetooth
- Цена: ~$80–100/устройство
- Управление: GPRS-команда с бэкенда (Teltonika Codec 12 protocol)

Альтернатива для упрощённой интеграции — **StarLine E96 BT:** CAN-шина + GSM + GPS + официальный fleet API (telematics.starline.ru). Всё в одном, но $150–250/авто и дороже в установке. Оправдано при 50+ авто когда важна надёжность интеграции.

## Модель безопасности

```
Арендатор получает OTP-код → открывает бокс → берёт ключ → садится

Если попытка использовать вне окна бронирования:
  → код не работает (Bluetooth-бокс)

Если уехал и не вернул в срок:
  → бэкенд → команда на FMB125 → реле отрубает иммобилайзер → машина глохнет

Если угон:
  → GPS-координаты в реальном времени
  → remote cut engine
  → данные для полиции
```

Идентификация до выдачи кода: арендатор верифицирован, депозит захолдирован, оба условия должны быть выполнены — только тогда OTP генерируется.

## Стоимость на авто

| Компонент | Цена |
|---|---|
| Bluetooth ключ-бокс (Igloohome или аналог) | $80–120 |
| Teltonika FMB125 | $80–100 |
| Реле × 2 + проводка | $15–25 |
| Установка автоэлектриком | $50–80 |
| **Итого** | **$225–325/авто** |

Для MVP с механическим боксом (ручной код): ~$150–180/авто.

---

## Кто платит за установку

Три модели:

**A. Хост платит сам** — снижает порог входа для CarPal, но часть хостов откажется. Работает если платформа даёт достаточный поток аренд в первый месяц.

**B. CarPal субсидирует** — $225–325/авто × 20 первых машин = $4,500–6,500. Возвратно через удержание из выплат (например, $15/мес пока не окупится). Снижает барьер для первых хостов.

**C. Рассрочка через платформу** — хост не платит сразу, CarPal удерживает ~10% из каждой выплаты до погашения стоимости оборудования.

## Backend-интеграция (что нужно от разработки)

- Teltonika Codec 12: отправка GPRS-команды на устройство (lock/unlock/cut engine)
- Igloohome API или аналог: генерация time-limited PIN per booking
- Логика: при создании бронирования → генерировать OTP с окном = время аренды → при возврате авто или истечении срока → команда на иммобилайзер если авто не на месте
