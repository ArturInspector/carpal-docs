# Use Cases

## Городская аренда (часы)

Бишкек, 2–8 часов. Арендатор: местный или командировочный. Авто: sedan / crossover. Передача ключей: встреча в оговорённом месте.

Минимальный UX: забронировал → встретился → поехал → вернул → депозит разморожен.

## Суточная аренда

1–3 дня. Иссык-Куль, Чолпон-Ата. Турист или местный. Требования: страховка на срок поездки, стабильное покрытие вдоль маршрута (есть).

## Горный маршрут (ключевой use case)

3–7 дней. Сон-Куль, Таш-Рабат, Каракол. Обязателен 4x4. Часть маршрута — без покрытия.

Специфика:
- Передача ключей в Бишкеке до отъезда
- Возврат в Бишкеке (или по договорённости)
- Ущерб без сети: фото сохраняются локально, синкаются при появлении сети
- Оффлайн-доступ к договору и контактам — обязателен

Это главный кейс для которого нужен 4x4 инвентарь и верифицированные хосты. Без него ценностное предложение для иностранного туриста слабее.

## Что не покрываем (MVP)

- Трансфер в аэропорт — нужен водитель, это не наш P2P
- Кросс-граничные поездки (Казахстан, Таджикистан) — страховка и юрисдикция не решены
- Доставка авто к арендатору — MVP: самовывоз
