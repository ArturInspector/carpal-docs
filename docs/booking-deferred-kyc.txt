CarPal — Сценарии аренды (deferred KYC, Turo-стиль)
====================================================

ИДЕЯ
- Минимум трения на входе. Имя / KYC / права спрашиваем ПОСЛЕ выбора возраста, срока и ввода карты.
- На «Арендовать» сразу ставим pre-auth холд на карту. Списываем (capture) только после прохождения верификации.
- KYC = биометрия (Didit) + водительские права + подтверждение ФИО.
- Цель: турист доходит до «Арендовать» не регистрируясь. Аккаунт создаётся в конце, когда верификация пройдена.


СПОСОБЫ ОПЛАТЫ
- Карта (Visa/MC): можно платить ДО верификации. Холд → KYC → списание. Доступно гостю.
- QR (локальный): только зарегистрированный + KYC и права подтверждены. QR показывается ТОЛЬКО после верификации, оплата сразу одним шагом, без холда.
- Почему QR гейтится: QR не умеет pre-auth холд / chargeback как карта. Личность должна быть подтверждена ДО оплаты, иначе нечем покрыть риск.


ЧТО СОБИРАЕМ У ГОСТЯ НА ШАГЕ КАРТЫ (до аккаунта)
- First name (как в правах)
- Last name (как в правах)
- Country
- Mobile number (код страны + номер)
- Возраст
- Карта
Текст согласия под телефоном:
"By providing a phone number, you consent to receive automated text messages with trip or account updates."


ВОЗРАСТ
- На шаге карты возраст заявляется вручную (self-declared).
- Сразу сверяем с лимитом владельца (владелец задаёт мин. возраст / стаж).
- Ниже лимита → не пускаем дальше, до холда.
- Позже возраст подтверждается документом в KYC. Если документ не совпал с заявленным → decline (см. ПРОВАЛ).


ПОДТВЕРЖДЕНИЕ ВЛАДЕЛЬЦА (instant-book)
- Бронь авто-подтверждается, арендатор не ждёт ручного «ок».
- У владельца есть 20 мин: «Разрешить» или «Отменить».
- Не нажал за 20 мин → авто-подтверждение.
- Отменил → холд снимается, деньги возвращаются.
- Авто-подтверждение безопасно, т.к. арендатор уже прошёл KYC и подходит под лимиты владельца.
- [TBD] длина окна: 20 мин коротко для живого хоста (Turo book-request ~8 ч). Для MVP ок, обсудить.


ПРОВАЛ ВЕРИФИКАЦИИ (после холда)
Срабатывает если: биометрия не прошла / права невалидны / возраст из документа не совпал или ниже лимита.
- Оплата отклоняется (decline), холд снимается.
- Бронь отменяется.
- Карта сохраняется токеном на профиль/номер. При повторе не вводит данные карты — выбирает сохранённую.


====================================================
БАЗОВЫЙ ФЛОУ (гость, оплата картой)
====================================================
поиск → карточка авто → возраст → сверка с лимитом владельца → срок →
шаг карты (имя, страна, телефон+согласие, карта) → «Арендовать»
→ pre-auth холд
→ KYC: биометрия → права → подтверждение ФИО
→ создаём аккаунт (карта уже привязана)
→ окно владельца 20 мин (или авто-подтверждение)
→ списание (capture)
→ бронь CONFIRMED

Ветки:
- KYC провален → decline, холд снят, карта сохранена, бронь отменена.
- Владелец отменил в 20 мин → холд снят, деньги назад.


====================================================
СЦЕНАРИИ ПО СОСТОЯНИЮ АРЕНДАТОРА НА «АРЕНДОВАТЬ»
====================================================
Различаем по тому, что уже пройдено. До-спрашиваем только недостающее, дальше — общий хвост (окно владельца → capture → CONFIRMED).

1) НЕ ЗАРЕГИСТРИРОВАН (гость)
- Полный путь как в базовом флоу.
- Оплата: только карта. QR недоступен.
- В конце создаём аккаунт.

2) ЗАРЕГИСТРИРОВАН, НИЧЕГО НЕ ПРОШЁЛ
- Аккаунт есть, верификации нет.
- Карта новая или сохранённая → «Арендовать» → холд → полный KYC (биометрия + права + ФИО) → окно владельца → capture.
- Оплата: только карта.

3) ЗАРЕГИСТРИРОВАН, НЕТ ПАСПОРТА / ПРАВ (биометрия пройдена)
- Холд → до-спрашиваем только права + ФИО/паспорт → окно владельца → capture.
- Оплата: только карта (пока права не подтверждены — QR нет).

4) ЗАРЕГИСТРИРОВАН, БИОМЕТРИЯ НЕ ПРОЙДЕНА (документы есть)
- Холд → до-спрашиваем только биометрию → окно владельца → capture.
- Оплата: только карта.

5) ЗАРЕГИСТРИРОВАН + ПОЛНОСТЬЮ ВЕРИФИЦИРОВАН (возвращающийся)
- Ничего не до-спрашиваем.
- Карта: выбрал сохранённую → холд → окно владельца → capture. 1-в-1 как Turo book.
- QR: доступен. Выбирает QR → платит сразу одним шагом → окно владельца → CONFIRMED.


МАТРИЦА: ЧТО ДО-ЗАПРАШИВАЕМ
| Состояние                  | Биометрия | Права+ФИО | QR  | До-спрашиваем              |
|----------------------------|-----------|-----------|-----|----------------------------|
| Гость (не рег.)            | –         | –         | нет | биом + права + ФИО, аккаунт|
| Рег., ничего               | –         | –         | нет | биом + права + ФИО         |
| Рег., нет прав/паспорта    | есть      | –         | нет | права + ФИО                |
| Рег., нет биометрии        | –         | есть      | нет | биометрия                  |
| Рег., верифицирован        | есть      | есть      | да  | ничего                     |


====================================================
QR-ОПЛАТА (детально)
====================================================
- Доступна только зарегистрированному с подтверждёнными KYC + правами.
- До верификации QR не показывается. Гостю и неверифицированному — только карта.
- После подтверждения KYC+прав на экране оплаты появляется QR.
- Платит всё сразу, без холда — прямой платёж.
- Дальше как обычно: окно владельца 20 мин → CONFIRMED. [TBD] при отмене владельцем по QR — механизм возврата отличается от карты (нет холда → нужен refund).
