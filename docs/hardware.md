# Hardware

## MVP: FMB009 + ключ-бокс

Трекинг во время поездки — FMB009. Передача ключей — физически или бокс. Никакого keyless.

## FMB009

GPS-трекер. Даёт координаты в реальном времени, лог поездки, событие зажигания. Управление через GPRS (Teltonika Codec 8/12). Один DOUT — для MVP не используется.

Цена: уточнить у дистрибьютора в КГ/КЗ.

## Ключ-бокс

Механические — не брать. Хост забудет сменить код.

Bluetooth/OTP (~$80–120): код работает только в окно бронирования, генерируется платформой через API. Продукты с API: Igloohome KeySafe Mini, Master Lock 4401DLH.

Крепление: фаркоп (лучший вариант) → под бампером на раму (если нет фаркопа) → колёсный диск не использовать (коррозия, риск повреждения).

## Безопасность

Бокс один из шести слоёв, не центральный:
KYC → депозит в холде → OTP-код → FMB009 трекинг → страховка хоста.

Профессиональный угон бокс не останавливает. Трекер — да.
