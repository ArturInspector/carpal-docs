# Бизнес-модель

## Механика (MVP)

Комиссия с каждой аренды: **15–20% от суммы сделки**. Удерживается с хозяина при разморозке эскроу.

*[CTO: решение по ставке принято? Commission split с арендатором рассматриваешь?]*

## Unit Economics (драфт — верифицировать реальными цифрами)

Допущения:
- Средний чек: 5,000–15,000 сом/сутки (4x4 горный — ближе к верхней границе)
- Комиссия 15%: 750–2,250 сом с транзакции
- 50–100 транзакций/мес → breakeven по infrastructure ($30–50/мес Railway + Vercel + R2)

*[CTO: реальные рыночные цены? Средний срок аренды по горному кейсу?]*

## Подписка для хостов (пост-MVP)

Premium listing: приоритет в поиске, верификационный бейдж, аналитика. Фиксировано в месяц.

Смысл запускать когда на платформе достаточно хостов чтобы premium давал реальное преимущество — иначе продать не получится.

## Страховка как addon (пост-MVP)

Если договорились со страховщиком — перепродажа per-trip полисов с маржой. На горизонте 1–2 лет это может превысить комиссионный доход.
