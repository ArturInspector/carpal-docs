# Проблемы

Только реальные, только подтверждённые. Без спекуляций.

## Блокируют запуск

**Передача ключей (городская аренда)**
Физическая встреча для 2-часовой аренды — плохой UX. Решения: ключ-бокс или keyless. Keyless — не MVP. Ключ-бокс: механический (риск человеческого фактора) или Bluetooth OTP ($80–120/шт). Решение не принято.

**Холдирование платежей**
Переговоров с банком нет. Pre-auth через эквайринг — рабочая альтернатива без банковского договора. Иностранные туристы платят Visa/MC — нужен международный эквайринг.

**Страховка**
P2P страхового продукта в КР нет. Без неё хост несёт полный риск сверх депозита. Переговоров со страховщиком нет.

## Ограничивают масштаб

**Cold start**
Без машин нет арендаторов, без арендаторов незачем хостам идти. Первые 10 машин — вручную, через автопарки, с нулевой комиссией первые 2 месяца.

**Верификация иностранных водителей**
Joldo не покрывает иностранцев. MVP: selfie + doc match + повышенный депозит.

**Арбитраж ущерба**
Кто решает спор — команда вручную. Не масштабируется, но достаточно для MVP.
