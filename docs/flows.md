# Флоу

## Онбординг хоста

```
Регистрация → загрузка авто (фото, документы) → верификация платформой
→ установка FMB009 → авто в листинге
```

Опционально: оплата "выдвижение в топ".

## Бронирование

```
Поиск (дата, локация) → карточка авто → выбор слота
→ checkout: холд платежа + подпись договора
→ хост подтверждает → статус CONFIRMED
```

## Передача ключей

```
Встреча или ключ-бокс
→ фото-осмотр: 4 стороны + салон, оба подтверждают
→ фиксация состояния: царапины, топливо
→ ключи получены → поездка начата
```

Нештатное: хост не пришёл через 15 мин → деньги возвращаются, инцидент в профиль хоста.

## Поездка

```
Таймер активен → FMB009 трекает авто
→ SOS-кнопка всегда доступна
```

## Возврат и оплата

```
Фото-осмотр при возврате
→ [нет претензий]: хост подтверждает → платёж проходит, хост получает сумму - 15%
→ [претензия]: фиксируется, депозит удерживается → арбитраж вручную
```

Нет ответа от хоста X часов → автоподтверждение возврата.
