# Принятые решения

Только то что зафиксировано. Не гипотезы, не планы — решения.

## Продукт

- CarPal — P2P маркетплейс, не прокатная компания. Авто не наши.
- Гибридный формат: владелец использует авто как личное, иногда сдаёт в аренду.
- MVP — только Бишкек, только Кыргызстан.
- Комиссия — 15% с хоста при каждой выплате.
- Первые хосты — автопарки 5–15 машин, не физлица.
- Оффер для первых хостов: 0% комиссии 2 месяца + мы ставим чип за свой счёт.

## Hardware

- FMB009 — только трекинг во время поездки. Никакого keyless на MVP.
- Передача ключей — физически или механический/Bluetooth-бокс.
- Keyless (CAN-шина, StarLine-интеграция) — не MVP.

## Что НЕ решено

- Тип ключ-бокса: механический vs Bluetooth OTP
- Кто платит за установку FMB009: хост / CarPal субсидирует / рассрочка
- Эскроу / холдирование платежей: переговоры с банком не начаты
- Страховка: решения нет
- ОсОО: зарегистрировано или нет
