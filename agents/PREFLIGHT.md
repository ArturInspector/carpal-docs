# Agent Preflight: до начала задачи

*Проверяй перед тем как писать код или менять схему.*

## 1. Прочитал?

- [ ] `CLAUDE.md` в корне проекта
- [ ] Релевантные файлы из `docs/` (хотя бы заголовки)
- [ ] Текущий стейт файлов которые будешь менять

Не читал — читай сначала.

## 2. Понимаешь задачу?

- [ ] Что изменится в БД?
- [ ] Какие endpoint'ы затронуты?
- [ ] Есть ли финансовые операции?
- [ ] Затрагивает ли эскроу / верификацию / стейт-машины?

Не понимаешь — читай docs или задай вопрос CTO (см. CTO-INTERVIEW.md).

## 3. Security implications?

- [ ] Новые endpoint'ы — нужна авторизация?
- [ ] Пользовательский ввод — валидируется на границе?
- [ ] Деньги — integer minor units, не float?
- [ ] Секреты — только env vars, не в коде?

Если да — флажишь явно до реализации.

## 4. Нужно спросить CTO?

Хотя бы один пункт из CTO-INTERVIEW.md срабатывает — стоп, спрашиваешь сначала.
